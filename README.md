# 🐕 Dog Crossing

A retro-style arcade game inspired by Frogger. Guide your dog across traffic, collect bones, and outrun the dog catcher!

## 🎮 [Play Game Now](https://petertuttle05.github.io/dog-crossing/)

Click the link above to play the game online!

---

## Game Features

- **Cross the Road**: Navigate your dog across busy traffic lanes
- **Bone Collectibles**: Grab bones for bonus points
- **Dog Catcher**: Escape the pursuing dog catcher as you progress
- **Progressive Difficulty**: Speed increases with each stage
- **High Score Tracking**: Your best score is saved locally

## Controls

| Key | Action |
|-----|--------|
| **→ Right Arrow** | Move Forward (Primary objective) |
| **← Left Arrow** | Move Left |
| **↑ Up Arrow** | Move Up |
| **↓ Down Arrow** | Move Down |
| **Space** | Pause/Resume Game |

## Game Mechanics

- **Start**: Click the START RUN button to begin
- **Scoring**: +1 point for each forward move without collision
- **Bones**: Collect bones for +1 point each
- **Lives**: You have 1 life - one collision with a car or the dog catcher ends your run
- **Difficulty**: Game gets progressively harder as you advance stages

## Technical Stack

- **HTML5 Canvas** for rendering
- **Vanilla JavaScript** (ES6+)
- **Web Audio API** for retro beeps and boops
- **localStorage** for high score persistence
